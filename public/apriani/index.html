Sistem Monitoring dan Pengangkatan Sampah Berbasis Internet of Things (IoT) pada Saluran Irigasi Persawahan

Solusi terintegrasi untuk menjaga kelancaran debit air dan kebersihan saluran irigasi persawahan secara cerdas dan otomatis. Proyek ini menggabungkan rekayasa perangkat keras mikrokontroler ESP32, arsitektur *cloud backend* AWS untuk penanganan data telemetri, serta antarmuka aplikasi Android mobile sebagai pusat monitoring dan kendali jarak jauh.

Fase 1: Riset & Prestasi Nasional

Pengembangan Project – PKM-KC / PIMNAS ke-37 & Innovillage Social Project 2024

  • Pengembangan Sistem Otomatis: Berkontribusi dalam rancang bangun sistem monitoring dan pengangkatan sampah otomatis menggunakan mikrokontroler ESP32 pada saluran irigasi persawahan.
  • Perancangan Desain Aplikasi: Berperan dalam perancangan desain antarmuka aplikasi (UI) sebagai bagian integral dari sistem pemantauan visual.
  • Manajemen Keuangan & Kearsipan: Bertanggung jawab penuh dalam penyusunan laporan keuangan anggaran hibah dan dokumentasi project secara transparan dan akuntabel.
  • Kolaborasi Tim: Berkolaborasi secara intensif bersama tim lintas fungsi dalam proses pengujian teknis lapangan dan penyempurnaan sistem.
ESP32 IoT Automation UI Design Laporan Keuangan Dokumentasi Proyek PIMNAS 37
Fase 2: Riset Lanjutan & Skripsi Sarjana

Pengembangan Lanjutan – Skripsi, Universitas Syiah Kuala

  • Aplikasi Android Cerdas: Mengembangkan aplikasi Android khusus untuk monitoring berkala dan pengendalian operasional perangkat pengangkat sampah dari jarak jauh.
  • Integrasi AWS Cloud: Mengimplementasikan proses pengambilan data telemetri dari AWS Cloud untuk menampilkan status real-time kondisi saluran dan perangkat pada aplikasi Android.
  • Sinkronisasi Data End-to-End: Mengintegrasikan komunikasi data dua arah yang stabil antara Aplikasi Android, AWS Cloud, dan Perangkat ESP32.
  • Evaluasi Usability Ilmiah (SUS): Melakukan evaluasi usability aplikasi menggunakan instrumen System Usability Scale (SUS) untuk menjamin efektivitas, efisiensi, dan kenyamanan pengguna.
